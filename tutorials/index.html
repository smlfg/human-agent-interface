01 / Human Ownership

Der Mensch setzt Ziel, Risiko und Abbruchlinie.

Harness Map

Das Harness ist keine App-Schale. Es ist die Entscheidungskette.

Jeder Block hat eine andere Aufgabe. Wenn ein Block fehlt, sieht Agentenarbeit produktiv aus, aber der Mensch verliert Kontrolle.

Waehle ein Tool. Die Website zeigt, welche Rolle es im Harness hat, welches Artefakt es liefern soll und wo der Mensch stoppen muss.

Runbook

          
Eine Agenten-Session laeuft in sechs kontrollierten Bewegungen.

          
Oeffne die Schritte. Jeder Schritt ist ein eigener Gate-Punkt.

        


        

          
          

            
Das Tool liest Kontext, HAI-Ziel und Auftrag. Output: Was ist klar, was ist unklar, welche Artefakte waeren sinnvoll?

          


          
          

            
Der Plan nennt Artefakt, Beleg und Human Gate pro Schritt. Noch keine Datei-Aenderung.

          


          
          

            
Der Agent arbeitet klein. Wenn der Ansatz kippt oder breiter wird, stoppt der Lauf.

          


          
          

            
Erfolg wird als Beleg sichtbar: Checks, Smoke-Test, Doku-Struktur, Screenshot oder Diff.

          


          
          

            
Der Agent sucht Scope Drift, falsche Claims, fehlende Belege und riskante Empfehlungen.

          


          
          

            
Der Mensch bekommt keine Rohgeschichte, sondern: geaendert, Belege, offen, naechste Entscheidung.
