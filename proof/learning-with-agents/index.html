Learning in public

I use agents to make learning active.

Not to outsource understanding. To turn one blocked concept into a bounded interface, then test whether I can carry the pattern without it.

Open the learning editions See the learning loop
Public scope

Recorded 23 September 2026. Part of the proof.

What is public here

Four self-contained learning interactions. The artifacts are German because they were built for real study work.

  • Original public examples, not course PDFs
  • No personal learning data or private session logs
  • No live agent, account, or backend connection
01 / The loop

The loop

The agent helps shape the practice. The learner still has to do it.

The proof is not that an agent can explain a subject. The proof is a smaller claim: it can help turn a vague blockage into deliberate practice with a visible next move.

01

notice

Name the real block.

Not “I need to learn machine learning.” A concrete breakdown: one update, one proof step, one runtime pattern.

02

bound

Build one small surface.

The agent turns the selected problem into a constrained explainer, visual or drill — not a general tutor chat.

03

act

Recall and transfer.

The screen is a prompt to calculate, classify, or trace. Hints can disappear; a new case checks whether the pattern moved.

04

revise

Keep the failure useful.

A wrong answer becomes the next bounded repair, rather than a reason to restart the whole subject or the whole system.

Agent role: Creates a focused practice surface from an explicit learning constraint.

Human role: Chooses the problem, performs the work, checks transfer, and owns the decision to keep or discard the artifact.

02 / Editions

Four learning editions

Different subjects. The same refusal to stay passive.

Each edition keeps one learning mechanic visible: identify the motor, calculate the update, reconstruct the representation, or follow the transformation through a network.

01

03 / Boundary

Honest boundary

These are learning artifacts, not a claim of finished mastery.

A public interface can show a method without pretending to publish grades, course materials, a universal tutoring model, or private agent traces.

01

What the page demonstrates

Agents can be placed inside a bounded learning loop where the human still has to retrieve, calculate, compare, and transfer.

02

What the page does not demonstrate

It is not official course material, a substitute for teaching, an autonomous tutor, or evidence that a concept is learned because an interaction was opened.

Scope: a public interface can show a method without pretending to publish grades, course materials, a universal tutoring model, or private agent traces.
