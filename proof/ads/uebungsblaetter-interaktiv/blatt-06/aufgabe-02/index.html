Dein Mikro-Schritt

Starte den echten Suchlauf und beobachte, wann ein Feld grün, ein Konflikt rot und eine Wahl wieder zurückgenommen wird.

Aufgabenvertrag: Die Option -d schaltet die Anzeige; ohne sie bleibt der Solver headless.

if (display) { board->setSquare(row, col, Gruen); board->render(); schlafe_ms(delay); }

Ein Zustandswechsel wird erst durch render() sichtbar; die Pause gehört zwischen die Zustände.
Beim Backtrack erst resetSquare(row,col), dann erneut rendern. Sonst zeigt die Oberfläche einen Zustand, den der Solver längst verlassen hat.
