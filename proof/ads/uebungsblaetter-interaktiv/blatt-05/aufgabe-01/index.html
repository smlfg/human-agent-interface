Maximum Subarray

PB05 · 01/04

Dein Mikro-Schritt

Klicke im Quellarray zuerst auf den Startindex 2. Baue danach die zusammenhängende Summe Element für Element auf.

Nicht die größten Einzelwerte sammeln: Die Teilfolge muss lückenlos sein.

Gesucht: zusammenhängende, nichtleere Teilfolge Ergebnis: Startindex, Endindex, maximale Summe Lab: naive Θ(n³) + Summenwiederverwendung Θ(n²)

1 · Am Quellarray entlang

Aktuelle Summe: 0 · Auswahl: noch keine

Fixiere zuerst i = 2. Der Endindex j darf danach nur nach rechts wandern.
Rechne: 59 → 85 → 32 → 90 → 187. Auch das negative −53 bleibt in der zusammenhängenden Folge.

2 · Welche Schleife kann weg?

3 Schleifen

Naiv

i wählt den Start, j das Ende, k summiert jedes Teilfeld erneut.

sum(i..j) = a[i] + … + a[j]
2 Schleifen

Summe wiederverwenden

Bei festem i gilt beim nächsten Ende: sum += a[j].

sum(i..j) = sum(i..j−1) + a[j]

Was ist die echte Verbesserung?
