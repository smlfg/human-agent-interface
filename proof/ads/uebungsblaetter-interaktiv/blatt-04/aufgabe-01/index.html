Dein Auftrag

Implementiere SelectionSort, InsertionSort und MergeSort selbst im lokalen Lab.

Erster Mikro-Schritt: Öffne lab/sorts.cpp und bearbeite nur SelectionSort.

void selection_sort(std::vector<int>& a); void insertion_sort(std::vector<int>& a); void merge_sort(std::vector<int>& a);

1 · Mechanik vor Code

AUSWÄHLEN

SelectionSort

Suche im Restfeld das Minimum und tausche es an die nächste feste Position.

[4 2 3]min im Rest: 2[2 | 4 3]

immer Θ(n²)

EINFÜGEN

InsertionSort

Nimm das nächste Element und schiebe es im bereits sortierten Präfix nach links.

[2 4 | 3]3 wandert vor 4[2 3 4]

best Θ(n), sonst Θ(n²)

TEILEN + MISCHEN

MergeSort

Teile bis zu Einzelelementen. Führe danach zwei sortierte Teilfelder geordnet zusammen.

[4 2] + [3 1]rekursiv → [2 4] + [1 3]merge → [1 2 3 4]

immer Θ(n log n)

2 · Welcher Test beweist Sortierung?

Wähle den nächsten sinnvollen Schritt nach einem Testlauf.

Beobachten ist kein Beweis: Eine lange Zahlenzeile kann sortiert aussehen, obwohl Duplikate fehlen oder ein Randfall kaputt ist.
MergeSort: Splitten erzeugt nur kleine Teilprobleme. Sortiert wird das Gesamtfeld erst, wenn zwei sortierte Hälften korrekt zusammengeführt werden.
