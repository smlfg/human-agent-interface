Originalauftrag, kompakt

logtable liest -start, -step, -base, -perline und einen Positionsparameter count. Ohne count oder bei 0 werden alle Werte mit cin erfragt.

Defaults: 1.0 · 1.0 · 2.0 · 5. Abschluss: Beispielwerte und Ausgabeformat im echten C++20-Testtreiber.

2 · Hilfe, gestuft

    

    
Der Nenner legt die Basis fest. Der Zähler gehört zum aktuellen Tabellenwert x.

    
log_a(x) = ln(x) / ln(a). Definiert ist das nur für x > 0, a > 0 und a != 1.

4 · Implementierungsvertrag

    
    
      
  • Optionen: args.double_option("start", 1.0), analog step/base, und int_option("perline", 5).
    • 
      
  • count = args.int_pos(0, 0); bei 0 oder fehlendem Parameter alle fünf Werte via cin lesen.
    • 
      
  • Jeder Eintrag zeigt x mit einer und log(x) mit vier Nachkommastellen; nach jeweils perline Einträgen folgt ein Zeilenumbruch.
    • 
      
  • Vor dem Rechnen ungültige Basis, nichtpositive x-Werte sowie perline/count <= 0 abweisen.
