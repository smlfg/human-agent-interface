    Abschluss · Definition und Beweisidee

    Noch gesperrt: Beende einen verschachtelten Trace und wähle danach die passende vereinfachte Definition — oder decke nach einem Versuch bewusst auf.

    f(x) =
    91für x ≤ 101x − 10für x > 101

    Beweisidee in drei Intervallen

    1. x > 101: Die Originaldefinition nimmt sofort den ersten Zweig und liefert x−10.
    2. 91 ≤ x ≤ 101: x+11>101, also wird der innere Aufruf direkt zu x+1; der äußere Aufruf führt schrittweise zum Wert 91.
    3. x < 91: Jeder sonst-Schritt hebt das Argument um 11 an. Nach endlich vielen Schritten erreicht der Trace das bereits behandelte Intervall.

    Terminierung: Unterhalb der Basisgrenze steigen offene Argumente; oberhalb 100 wird ein Aufruf sofort geschlossen. Eine formale Variante kann die endliche Distanz zum Intervall [91,101] als Maß verwenden.

    Testidee: Prüfe alle x von −100 bis 200 gegen die vereinfachte Fallunterscheidung, besonders 100, 101 und 102.

    Sitzt die Doppelrekursion?

    Prüfungsartefakt: korrekter Aufruftrace, Grenze 101, vereinfachte Definition und Terminierungs-/Intervallargument.
