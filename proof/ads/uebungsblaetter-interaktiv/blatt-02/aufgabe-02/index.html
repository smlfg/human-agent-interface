Ein intvec wächst, ohne Werte zu verlieren

Aufgabe 02

Originalauftrag, kompakt

Verwalte capacity, size und arr selbst. Bei vollem Array verdoppelt ivec_pushback die Kapazität und erhält alle alten Werte.

Abschluss: die Verträge von init, clear, pushback, at und sum im C++20-Lab erfüllen.

1 · Werkbank: pushback(17)

size 2 capacity 2 arr A

anzuhängen: 17

Der alte Block A enthält 4 und 9. Was muss vor dem Umschalten passieren?

2 · Hilfe, gestuft

Während des Wachstums existieren kurz zwei Blöcke. Der alte Block bleibt die Quelle, bis seine size benutzten Werte kopiert sind.

Reihenfolge: neuen Block mit 2 * capacity anlegen → Indizes 0 .. size-1 kopieren → alten Block mit delete[] freigeben → arr/capacity umstellen → Element an arr[size], dann size erhöhen.

3 · Speicherfehler erkennen

Welche Aussage muss nach ivec_clear(&v) gelten?

4 · Funktionsverträge

ivec_init(v, cap)
frischer Block für cap ints; size == 0
ivec_clear(v)
Arrayfreigabe mit delete[]; leerer, gefahrloser Zustand
ivec_pushback(v, x)
hängt an; verdoppelt nur wenn voll; erhält alte Werte
ivec_at(v, i)
liefert Referenz für i < size, sonst Prozessabbruch
ivec_sum(v)
summiert genau die size benutzten Werte

5 · Echter Lab-Abschluss

Ersetze die TODOs in lab/intvec.cpp. Die Starterdatei enthält bewusst keine Komplettlösung.

cd uebungsblaetter-interaktiv/blatt-02/aufgabe-02/lab
./run-tests.sh

Der dependency-freie Runner überträgt die offiziellen Prüfungen für Initialisierung, Freigabe, Wachstum bis Kapazität 2048, Zugriff und Summen. Zusätzlich prüft ein separater Prozess, dass ein ungültiger ivec_at-Zugriff abbricht.
