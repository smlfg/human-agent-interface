Big-O bezeugen

PB03 · 01/06

Vorher ansehen

Short · 1:09

Andere Zahlen als deine Aufgabe — bewusst. Die Mechanik überträgst du selbst.

Sofort-RecallReicht es, wenn die Ungleichung nur für n = n₀ stimmt?

Dein Auftrag

f(n) = 3n + 17
g(n) = 2n

Finde konkrete Werte für c und n₀, die den formalen Beweis tragen.

f ∈ O(g) ⇔ ∃ c ≥ 0 : ∃ n₀ ≥ 0 : ∀ n ≥ n₀ : f(n) ≤ c · g(n)

1 · Wähle deine Zeugen

Welche konkrete Wahl funktioniert? Trage beide Zahlen ein und prüfe sie.

Quantoren auf Deutsch: Du darfst erst ein festes c und ein festes n₀ wählen. Danach muss die Aussage für jedes n ab n₀ stimmen.
Umformen: 3n + 17 ≤ 2cn. Wähle c größer als 3/2; dann kann der verbleibende Abstand den konstanten Term 17 aufnehmen.

2 · Schließe den ∀-Schritt

Welche Begründung vollendet den formalen Beweis?

Musterweg

Bleibt gesperrt, bis du eine eigene Wahl geprüft hast – oder du öffnest ihn bewusst.

Wähle c = 2 und n₀ = 17. Beide Werte sind nichtnegativ.

Für alle n ≥ 17 gilt:

f(n) = 3n + 17 ≤ 3n + n = 4n = 2 · (2n) = c · g(n).

Damit existieren passende c und n₀, und die geforderte Ungleichung gilt für jedes n ≥ n₀. Also f ∈ O(g).

Prüfungsabschluss
