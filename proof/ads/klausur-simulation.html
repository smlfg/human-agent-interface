M1

Schleifen mit Notausgang

Konstruierter Transfer nach A1 und A4 der Aufgabensammlung.
10 P 
int countPairs(int a[], int n) {
  int c = 0;
  for (int i = 0; i < n; ++i) {
    if (a[i] < 0) return c;
    for (int j = i + 1; j < n; ++j)
      if (a[i] < a[j]) ++c;
  }
  return c;
}
  1. Was zählt c?
  2. Nenne eine konkrete Best-Case-Eingabe und die Laufzeit.
  3. Nenne eine Worst-Case-Eingabe, zähle die zentralen Vergleiche und gib Θ an.

Musterweg & Rubrik

  • c zählt Paare i<j mit a[i]<a[j] bis zum ersten negativen Element. (3 P)
  • Best: a[0]<0; sofortiger Rücksprung, Θ(1). (3 P)
  • Worst: kein negativer Wert, etwa streng steigend; Vergleiche (n−1)+…+1=n(n−1)/2, Θ(n²). (4 P)

9 P 
int evenSum(Node* p) {
  int s = 0;
  while (p != nullptr) {
    if (p->value % 2 == 0) s += p->value;
    p = p->next;
  }
  return s;
}

Gegeben ist head → 5 → −2 → 7 → 4 → nullptr.

  1. Trace p und s nach jedem Knoten.
  2. Welcher Wert wird zurückgegeben?
  3. Best und Worst für eine Liste der Länge k?

Musterweg & Rubrik

  • s: 0 nach 5, −2 nach −2, −2 nach 7, 2 nach 4; Rückgabe 2. (3 P)
  • p=p->next besucht jeden der vier Knoten genau einmal. (2 P)
  • Bei fester Listenlänge k gibt es keinen frühen Abbruch: Best = Worst = Θ(k). (4 P)

Konstruierter Transfer nach Aufgabensammlung A3.

int h(int n) {
  if (n <= 1) return 1;
  return n + h(n - 1);
}
  1. Berechne h(4).
  2. Stelle Basisfall und Laufzeitrekurrenz auf.
  3. Rolle die Rekurrenz aus und nenne die asymptotische Laufzeit.

Musterweg & Rubrik

bool hasDuplicate(int a[], int n) {

Array-Stack: 5–15 Zeilen C++

Konstruierter Transfer nach Aufgabensammlung A8.
14 P 
struct Stack {
  int* data;
  int capacity;
  int size;      // Anzahl gespeicherter Werte
};

bool push(Stack& s, int value) { /* ergänzen */ }
bool pop(Stack& s, int& out)   { /* ergänzen */ }

Implementiere beide Funktionen. Bei voll/leer soll false zurückkommen, sonst true. out erhält den entfernten Wert.

Musterweg & Rubrik

bool push(Stack& s, int value) {
  if (s.size == s.capacity) return false;
  s.data[s.size++] = value;
  return true;
}
bool pop(Stack& s, int& out) {
  if (s.size == 0) return false;
  out = s.data[--s.size];
  return true;
}
  • Konsistente size-Konvention und Grenzen. (4 P)
  • push korrekt. (5 P)
  • pop korrekt, out vor Rückgabe gesetzt. (5 P)

Greedy-Gegenbeispiel

Konstruierter Transfer nach Übungsblatt 6 und Vorlesungsstoff Greedy/Backtracking.
8 P

Münzen {1,3,4}, Zielsumme 6. Greedy nimmt immer die größte noch passende Münze.

  1. Welche Lösung findet Greedy?
  2. Gib eine bessere Lösung an.
  3. Warum widerlegt das die allgemeine Optimalität?
  4. Was würde Backtracking anders tun?

Musterweg & Rubrik

  • Greedy: 4+1+1, also drei Münzen. (2 P)

  • Eine konkrete Instanz mit schlechterem Greedy-Ergebnis reicht als Gegenbeispiel zur allgemeinen Optimalität. (2 P)
  • Backtracking verzweigt über Alternativen, verwirft unpassende Pfade und kann 3+3 finden. (2 P)
