Deine Mission

Du musst nicht „Rekursion können“. Lass zwei konkrete Eingaben laufen, erkenne die wiederholte Operation und ersetze sie durch eine Zeile.

Prüfungsauftrag: Bedeutung beider Funktionen nennen und jeweils einfach, nicht-rekursiv implementieren.

double F1(double x, unsigned int n) {
  if (n == 0) return 0;
  return x + F1(x, n - 1);
}

double F2(int n) {
  if (n < 2) return 0;
  return 1 + F2(n / 2);
}
C++ → Alltag: return = Ergebnis zurückgeben n - 1 = eine Runde verbrauchen n / 2 = bei int abrunden

Prüfungsabschluss

Schreibe beide nicht-rekursiven Rückgabezeilen. Es zählt die Bedeutung, nicht perfektes Tippen.

Musterweg

F1: x wird n-mal addiert, also n * x.

double F1sol(double x, unsigned int n) {
  return n * x;
}

double F2sol(int n) {
  return (int)log2(n);
}

Für positive ganze n gilt: F2 = ⌊log₂(n)⌋. Der Basisfall liefert auch für n = 0 den Wert 0; die Logarithmusform ist dort nicht definiert.
