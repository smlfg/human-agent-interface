Why human + agent interfaces?

Samuel chose Human Agent Interface because he sees the human and the agent as equal participants in the conversation. A conversation can produce useful work and still leave an important question unanswered: what has actually been decided?

Make the shared state visible

In a human–agent interface, either participant can initiate an idea or question the other. Equal standing in the conversation does not remove accountability: the human owns consequential changes to the work’s scope. A visible request, boundary and review point help both participants understand where they stand.

A historical learning example

The published October 2026 learning-day account describes a Notion path that selected the next open concept. It also recorded missing automatic feedback: marking a concept understood did not reach the tutor or calendar. That is an observation from that account, not a claim about the current system.

Imagine the learner marks “loops” understood and the tutor cannot see that update. The next lesson may repeat it. The useful interface question is: which state was read, when, and how does the learner correct it? A visible last-seen state and a way to confirm or challenge it make the gap discussable.

When a possible task appears

A Plaud recording or summary may capture a possible improvement mentioned in conversation without establishing that anyone decided to add it. Capture it as a proposal, identify who decides and keep it separate from the agreed task until that decision is made.
