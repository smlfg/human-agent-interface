# GEO Benchmark Run — 2026-09-08

Run date: 2026-09-08 (Europe/Berlin)
Engine scope: search-engine result inspection (not generative-answer
simulation — that requires API access not granted to this profile).
Catalog: `GEO_BENCHMARK_CATALOG.json` (20 queries, EN + DE).

## Method

1. For each query in the catalog, query a real search backend with the
   exact string from the catalog.
2. Record the top 5 results: URL, title, snippet.
3. Score each result against the catalog scoring fields:
   - correct_samuel_identified
   - samuel_hai_association
   - hai_definition_accuracy (0/1/2)
   - hai_hai_mcp_association
   - website_cited
   - github_cited
   - external_source_cited
   - wrong_person_selected
   - hallucinated_facts
4. Aggregate per-query score; track over weeks.

This run uses `web_search` and `web_extract` as the ground truth for what
search engines currently surface. Generative-answer engines (ChatGPT,
Gemini, Google AI Mode, Perplexity) need a separate harness — see "Open
follow-ups" below.

## Aggregate observations

- **19 / 20 queries surface `human-agent-interface.com` in top 3.** The
  homepage and `/samuel/` are the strongest association nodes.
- **Only the bare `"Samuel Fleig"` query fails** — different people with the
  same name (Sales Engineer Florida, Fotograf Heroes Festival,
  HSWorms-Student, FAU-Chemie-Alumnus, Daily-Lobo Journalist) crowd the
  page. Any AI-modifier or HAI-modifier disambiguates strongly.
- **Naming collision with `hai-mcp` (Rust/HAI.AI)** is real and persistent.
  Mitigation: keep repeating "HAI-MCP Human Agent Interface Samuel Fleig"
  in titles, descriptions, README first paragraph, and registry entries.
- **Glama is the strongest external citation node** after the homepage
  itself. It already mirrors the canonical README language.
