## Remaining gaps

1. The new `/what_it_is/deep-dive/` is local; not committed, not pushed,
   not deployed. Public GEO effect blocked until then.
2. Generative-answer engines (ChatGPT, Gemini, Google AI Mode,
   Perplexity) were not probed directly — this profile has no API
   access to them. The current benchmark measures search-result
   surfaces only.
3. The bare-name query `"Samuel Fleig"` still surfaces other people on
   page 1. Disambiguation needs either a `/samuel/#disambiguation`
   anchor, a Wikidata entry, or repeated co-mentioning of
   "AI Engineering / Heilbronn / HAI" near the name on every
   first-mention surface.
4. `hai-mcp` (HAI.AI Rust crate) and `mcp-server-hai` (Tencent) keep
   crowding our brand. There is no fix except brand repetition in
   every title/description/README first paragraph.
5. LinkedIn headline / X bio / Medium bio are not yet aligned with the
   canonical definition — needs Samuel's manual edit on each platform.
6. No external third-party citations exist yet (no blog mentions, no
   podcast appearances, no preprint, no IPAI directory entry).
7. GEO benchmark has only one run; improvement vs. time not yet
   measurable.
