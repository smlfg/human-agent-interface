Is HAI an agent?

HAI is an approach to the interface around agent work. An agent may use that interface to act; HAI makes the task, limits, evidence and decisions understandable to the people involved.

What each part does

An agent can inspect information, propose an action or carry out a permitted task. HAI provides a way to make the working agreement and the result visible: what was requested, what is in scope, what needs review and where work must stop. HAI-MCP is one implementation of that control layer.

Try the distinction

Imagine a person asks an agent to fix a signup form. The agent proposes changing the validation message. The agreed boundary is the form; changing the signup policy needs a human decision. The agent can question whether that boundary is sufficient, and the person can question the proposal. Both can initiate the conversation; the person owns a consequential change of scope.

The agent produces a patch and shows the relevant checks. The person compares those results with the request and decides whether to accept the work. The patch is an agent output; the visible boundary and review are part of the interface.
