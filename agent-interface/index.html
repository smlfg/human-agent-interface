What is an agent interface?

An agent interface is how you give an AI agent a task, see what it does, and decide when it may go further. One task can take you through a chat, a terminal, and a code review.

Describe the bug in chat

Imagine a signup form where typing three spaces in the name field lets you continue. An empty field already shows “Enter your name.” You want the same message when someone enters only spaces.

You tell the agent, “Change the name check in the signup form and add a test for spaces. Keep accepting names like Mary Ann. Show me the patch before merging.” That gives the agent a place to work, an example to test, and a point to stop.

Inspect the change in the terminal

The agent can use the terminal to edit the form and run its tests. In this example, the relevant part of the diff would be one line removed and one added.

- if (name === "") return "Enter your name";
+ if (name.trim() === "") return "Enter your name";

The check now ignores spaces at either end when deciding whether the field is empty. It leaves the name itself alone, including the space in “Mary Ann.”

To see whether the patch fixes the bug, run the new test against the old check first. Submitting three spaces should reproduce the failure. Run it again with the patch and look for the form to block submission and show “Enter your name.” A separate case should still let “Mary Ann” through.

For a visual example, follow a GUI agent observing, acting and verifying a draft.

Decide whether to merge

At review, you need the full diff and the output from those test runs. Check which files changed and which cases actually ran. If the report only says “all tests passed,” ask to see the spaces-only case before you approve the merge.

These interfaces overlap. The agent can bring terminal output back into chat, and you can review the diff there. The Human Agent Interface (HAI) method focuses on how you keep control across those steps. Here, you set the scope, inspect the evidence, and decide whether the change goes in.
