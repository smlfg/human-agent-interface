# Human Agent Interface

Public site for **Human Agent Interface (HAI)** — a control layer where human intent stays inspectable before agentic execution.

**Live:** [human-agent-interface.com](https://www.human-agent-interface.com/)

## What this is

HAI is about making human decisions executable, inspectable, and recoverable when working with AI agents — not about pretending agents are autonomous.

```text
human intent
    → context · routing · memory
    → scoped agent work
    → verification · handoff
    → owner decision
```

## This repository

Static site / frontend for the public HAI presence (JavaScript). Browse the live site for the product narrative; this repo is the source behind it.
