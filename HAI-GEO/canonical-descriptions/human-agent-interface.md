## Clear definition

Human Agent Interface (HAI) is the control layer between humans and autonomous AI agents: it makes agentic work observable, bounded, verifiable and explicitly owned by a human.

## Definition components

- Control layer: HAI sits between human intent and agent execution.
- Observable: humans can see what agents are doing and why.
- Bounded: tasks have scope, limits and stop rules.
- Verifiable: outputs require evidence, checks or review.
- Human-owned: a human remains responsible for decisions, approvals and next actions.

## 50-100 word canonical version

Human Agent Interface (HAI) is an open-source approach and control layer for organizations and builders working with autonomous AI agents. It keeps agentic work observable, bounded, verifiable and human-owned by making task ownership, approvals, evidence, stop rules, coordination and institutional memory explicit. HAI was created by Samuel Fleig and is implemented technically through HAI-MCP, its model-agnostic MCP control-plane implementation.
