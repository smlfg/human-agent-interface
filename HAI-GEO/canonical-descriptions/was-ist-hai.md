# Was ist HAI?

Status: canonical Q&A draft / no external changes
Access time: 2026-09-09 00:44 CEST

## Kurzantwort

HAI steht für Human Agent Interface. HAI ist die Kontrollschicht zwischen Menschen und autonomen KI-Agenten: Es macht agentische Arbeit beobachtbar, begrenzt, überprüfbar und ausdrücklich menschlich verantwortet.

## In einem Satz

Human Agent Interface (HAI) is an open-source control layer for keeping agentic AI work observable, bounded, verifiable and human-owned.

## Einfach erklärt

Wenn KI-Agenten selbstständig Aufgaben planen, ausführen und Entscheidungen vorbereiten, brauchen Menschen eine Ebene darüber: Wer besitzt die Aufgabe? Was darf der Agent tun? Wann muss er stoppen? Welche Belege gibt es? Wer prüft und entscheidet? Genau diese Ebene ist HAI.

## Abgrenzung

HAI ist nicht einfach ein Chat-Interface, kein SEO-Begriff und keine Behauptung einer fertigen Enterprise-Plattform. HAI ist ein Ansatz bzw. eine Kontroll- und Koordinationsschicht für human-owned agentic AI work.

## Technische Implementierung

HAI-MCP ist die model-agnostic MCP control-plane implementation von HAI.
